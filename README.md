## 📌 About The Project

Urban Mobility Data Analysis is an end-to-end data analytics project designed to explore ride-booking data and uncover meaningful business insights.

The project focuses on booking performance, ride cancellations, revenue patterns, vehicle utilization, customer ratings, and operational trends.

Using **Python, Pandas, NumPy, MySQL, and Power BI**, this project demonstrates the complete analytics workflow — from data cleaning and feature engineering to SQL-based analysis and dashboard visualization.

### 🎯 Project Goals

* 📈 Understand overall ride-booking performance.
* 🚘 Compare booking trends across vehicle types.
* 💰 Analyze booking value and revenue patterns.
* ❌ Investigate customer and driver cancellations.
* 🕒 Explore hourly, monthly, and weekday/weekend trends.
* 📍 Identify popular pickup locations and routes.
* ⭐ Examine customer and driver ratings.
* 📊 Present insights through Power BI visualizations.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Jupyter Notebook or VS Code
* MySQL
* Power BI Desktop

### Python Libraries

Install the main libraries using:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy mysql-connector-python
```

**What this command does:** Installs the Python libraries used for data manipulation, visualization, and database connectivity.

### Steps to Run

1. Clone or download this repository.
2. Open the Jupyter Notebook.
3. Update the dataset file path if required.
4. Install the necessary Python libraries.
5. Configure your MySQL connection securely.
6. Execute the notebook cells in order.
7. Run the SQL queries against the imported `rides` table.
8. Open the `.pbix` file in Power BI Desktop.

**Note:** The original raw dataset is not included. Reproducing the complete cleaning workflow may require the original source dataset. Update database credentials and local file paths before execution.
